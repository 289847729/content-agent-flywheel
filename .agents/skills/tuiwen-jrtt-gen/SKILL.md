# 推文转今日头条图文与 DOCX 生成技能 (tuiwen-jrtt-gen)

用于将长文、微信公众号推文或深度评测文章，一键转化为适合今日头条（Toutiao APP）平台生态传播与信息流推荐的**“深度爆款长图文”**，并直接输出带精美排版、可直接导入后台发布的 **DOCX 文件**。所有产物统一保存在 `outputs/今日头条/` 目录下。

---

## 核心交付原则

1. **统一归档到专用目录 (`outputs/今日头条/`)**：
   - 保持工作区整洁，所有今日头条相关的产物（Markdown、DOCX、封面图）**必须统一存放在 `outputs/今日头条/` 目录中**；
   - 执行前确保目录存在（不存在则自动创建 `mkdir -p outputs/今日头条`）。

2. **开箱即发布，拒绝做选择题**：
   - 绝不让用户在多个备选标题中挑选。AI 必须从头条推荐算法（CTR 点击率与信息流反差心理）出发，**直接选定并敲定唯一最优爆款标题**；
   - 严禁输出任何发布渠道的元说明（如严禁出现“【今日头条 · 深度图文专栏】| 发布渠道：今日头条 APP”这种无用废话标签）。

3. **高冲击力视觉门面（16:9 高清封面）**：
   - 今日头条信息流大图与长文封面采用标准 **16:9 横版比例**；
   - 绝不留空或使用图片占位符。必须使用生图工具（`generate_image`）生成质感强烈的科技大片级封面图，并在文章正文开头（主标题正下方）居中内嵌展示。原图保存在 `outputs/今日头条/YYYY-MM-DD-{主题}-今日头条封面.jpg`。

4. **双格式完整交付**：
   - **Markdown 文件**：规范结构化保存于 `outputs/今日头条/YYYY-MM-DD-{主题}-今日头条文案.md`；
   - **DOCX 文件**：调用内置排版脚本自动生成 `outputs/今日头条/YYYY-MM-DD-{主题}-今日头条文案.docx`。包含原生三线对比表、头条红小节装饰标（`▌`）、加粗数据视觉锚点及底部的热议互动框。

5. **专业客观，拒绝盲目吹捧**：
   - 头条读者高度重视真实性与争议点。行文必须基于母稿真实数据，客观指出与顶尖竞品/闭源模型的实际差距，树立专业、清醒、可信赖的创作者人设。

---

## 执行步骤与工作流

### 第一步：准备目录与分析母稿
1. 确保目标目录存在：`mkdir -p outputs/今日头条`；
2. 读取用户指定的公众号推文或长文 Markdown；
3. 提取 5 大核心事实维度：
   - **重磅新闻主体**：谁干了什么、打破了什么纪录、最新榜单成绩；
   - **前后代剧烈反差**：历史版本与现版本的暴涨跨度或关键技术代差；
   - **反常识的震撼细节**：与同行大厂迥异的打法（如全流程透明直播、成本极低、全部轨迹开源等）；
   - **普通人直接落地利益点**：不用看懂代码，打工人怎么用（本地离线客户端、长文总结、全模态处理、提速版等）；
   - **理性的客观冷思考**：与闭源/行业真正天花板的差距，不神化、不吹嘘。

### 第二步：依据头条算法敲定唯一最优爆款标题
依据今日头条信息流爆款公式直接敲定标题：
- **核心公式**：`[核心新闻事件/颠覆认知] + [国民级知名主体/反差动作] + [引发求证的悬念疑问]`
- **示范标杆**：`Claude 发布 90 分钟后 OpenAI 掀桌子！暴跌 99% 的 AI 价格战，到底便宜了谁？`
- **注意**：必须紧密贴合当前母稿的核心主题！**直接将敲定的最优标题作为 Markdown 开头第一行的唯一 `# 标题`**，严禁残留上一篇历史文章的标题，严禁在正文中添加 `> **敲定发布主标题**：...` 等多余元标签，保证文件开箱即直接发布。

### 第三步：生成 16:9 高清吸睛封面图
调用生图工具：
- 比例：`AspectRatio: '16:9'`
- 画面风格：强视觉冲击力、科技大片质感、光影层次分明、紧扣大模型/算力/登顶/极速主题，色彩搭配鲜明；
- 存储：原图统一保存在 `outputs/今日头条/YYYY-MM-DD-{主题}-今日头条封面.jpg`。

### 第四步：撰写头条深度长图文正文
标准段落脉络与排版要求，保存至 `outputs/今日头条/YYYY-MM-DD-{主题}-今日头条文案.md`：

```markdown
# [敲定发布的唯一最优标题]

![今日头条封面图](YYYY-MM-DD-{主题}-今日头条封面.jpg)

### 导语：[直击痛点与反常识引入]
这两天科技圈彻底炸锅了，所有人的目光都聚焦在同一件事上：**...**
[很多人第一反应是什么？反差在哪里？今天用人话拆清楚。]

---

### 一、[核心看点：榜单突然易主/技术指标暴涨]
[权威数据榜单介绍 + 当前头部排名 Markdown 三线表格]
[前后代跨度对比加粗高亮 + 架构技术细节]

---

### 二、[颠覆认知：罕见打法与底牌全公开]
[与众不同的透明度、直播细节、时间、成本数据清单]
[深入浅出的比喻（如公开独家菜谱）+ 对整个行业的降本价值]

---

### 三、[普通人落地：装在哪能用、怎么用]
[列出 4~5 个具体到日常打工人、手机用户的实际应用场景（客户端、离线、长文本、全模态等）]

---

### 四、[理性客观：先别急着吹，看清真实差距]
[对比最顶尖闭源/竞品数据的表格 + 客观差距点明]
[为什么即使有差距，依然是普通人的重大利好]

---

### 互动探讨
**[抛出 1~2 个具有争议性、态度站队性或场景启发性的热议问题，拉动评论区留言]**
```

### 第五步：调用排版引擎生成 DOCX
在技能目录下直接执行内置排版引擎，将文档输出至 `outputs/今日头条/`：
```bash
python3 {SKILL_DIR}/scripts/markdown_to_docx.py \
  --input "outputs/今日头条/YYYY-MM-DD-{主题}-今日头条文案.md" \
  --output "outputs/今日头条/YYYY-MM-DD-{主题}-今日头条文案.docx" \
  --cover "outputs/今日头条/YYYY-MM-DD-{主题}-今日头条封面.jpg"
```

### 第六步：交付验收与汇报
向用户完整汇报：
1. **敲定的爆款标题**及算法逻辑；
2. **DOCX 文档路径**（位于 `outputs/今日头条/`，排版开箱即用）；
3. **16:9 封面原图路径**与 Markdown 文案路径。
