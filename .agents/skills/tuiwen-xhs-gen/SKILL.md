# 推文转小红书文案与置顶封面生成技能 (tuiwen-xhs-gen)

用于将长文、微信公众号推文或深度评测文章，一键转化为适合小红书生态传播的**“爆款单图文案”**。

## 核心交付原则

1. **拒绝半成品，开箱即发布**：
   - 绝不让用户在多个备选标题或配图方案中做选择题。AI 必须从专业受众心理学与流量点击率角度，直接选定最优标题。
   - 绝不生成“图片占位符”或空白框。必须直接渲染出真实高清的 3:4 竖版设计卡片。
2. **置顶单图全景概括**：
   - 不采用容易割裂文字阅读节奏的多图插播形式。
   - 在笔记最顶部仅保留**一张置顶超级概括封面图**（以 Base64 格式内嵌在 Markdown 首行，导入小红书助手直接预览）。
    - 封面图由 `.agents/vendor/handraw-style/` 自动选择手绘风格、社媒/信息图构图与主题色，再由配置的 Gemini 生图模型生成主题插画；程序负责叠加标题，避免模型生成错别字。封面包含清晰的视觉主体、平台标题和少量辅助短句，不再固定使用同一套深色大字报模板。
3. **正文流畅一气呵成**：
   - 封面图后直接接入小红书正文。正文采用 Emoji 导航、短句成行、突出打工人利益点、保留客观冷思考、篇末设置评论区互动与高热垂直标签。

## 执行步骤与工作流

### 第一步：分析母稿与提取核心事实
1. 阅读用户指定的公众号推文或长文 Markdown；
2. 提取 4 大核心维度：
   - **核心爆点**：权威榜单成绩、突破性技术、最新版本数据；
   - **行业震撼**：与众不同之处（如价格暴降、直播开源、训练公开等）；
   - **普通人利益点**：打工人怎么用（离线本地跑、长文提炼、会议纪要等）；
   - **理性客观提醒**：与顶尖闭源/竞品的真实差距，不盲目神化。

### 第二步：敲定唯一最优爆款标题
依据小红书数码/科技/生活高 CTR 爆款公式直接敲定标题：
- **公式**：`[知名人物/大厂品牌] + [颠覆认知/强反差事实] + [悬念疑问] + [情绪表情]`
- **示范**：`雷军偷偷放大招！全球开源第一居然是小米？😱`
- **注意**：直接输出最终标题，不提供多余备选。

### 第三步：handraw-style + Gemini 生成置顶主题封面图
Studio 生成小红书文案时会自动调用项目内的 `studio/server/platform_cover.py`：

1. 从正文与当前小红书文案提炼平台核心卖点和视觉隐喻；
2. 从 `.agents/vendor/handraw-style/` 的 327 个风格、165 个构图和 36 个主题色中动态选择真实索引；
3. 将 handraw 风格特征、构图提示和文章主题组合成无文字生图提示词；
4. 调用 `IMAGE_MODEL` 配置的 Gemini 生图模型生成素材，自动裁切为 3:4；
5. 用 Pillow 叠加清晰中文标题并缓存到 `outputs/平台封面/`，再以内嵌 Base64 写入笔记。

旧版 `scripts/render_cover.py` 仅保留为独立兼容脚本，不再是 Studio 主路径。

准备好 JSON 配置（或通过参数传递）：
```json
{
  "top_tag": "科技前沿 · 重磅突发",
  "badge": "【全球开源榜首换人】",
  "highlight": "46 分登顶！",
  "title": "最强开源大模型",
  "subtitle": "突然是小米做的？！",
  "card_title": "【一图读懂】核心全貌速览",
  "items": [
    {"tag": "登顶榜首", "color": "#FF6700", "title": "...", "desc": "..."},
    {"tag": "透明厨房", "color": "#38BDF8", "title": "...", "desc": "..."},
    {"tag": "打工福利", "color": "#22C55E", "title": "...", "desc": "..."},
    {"tag": "理性客观", "color": "#F43F5E", "title": "...", "desc": "..."}
  ],
  "footer_tip": ">> 完整深度实测评测与上手方法，正文见 >>"
}
```

执行命令输出图片与获取 Base64：
```bash
python3 {SKILL_DIR}/scripts/render_cover.py \
  --json-str '{...}' \
  --output outputs/小红书/images/{name}_cover.jpg
```

### 第四步：编写小红书正文结构
正文按照如下标准结构组合：

```markdown
# [敲定的唯一最优爆款标题]

![小红书置顶封面图](data:image/jpeg;base64,...)

[黄金前 3 秒 Hook：打破传统认知，引发强烈好奇]

---

### 1️⃣ [核心看点一：登顶/突破/事实阐述]
[具体数据对比 + 万亿参数/技术亮点]

---

### 2️⃣ [核心看点二：与众不同的震撼细节]
[透明度、成本、背后的反常识动作]

---

### 3️⃣ [普通人能拿来干嘛？打工人直接抄作业]
🖥️ **[场景 1：电脑本地离线/客户端]**：具体痛点与爽点
📚 **[场景 2：超长文本处理]**：具体痛点与爽点
🎧 **[场景 3：全模态/会议提炼]**：具体痛点与爽点
⚡ **[场景 4：生成速度与低门槛版本]**：具体痛点与爽点

---

### 4️⃣ [理性冷思考：不吹不黑]
[客观指出差距，但说明为什么对普通人依然是巨大福利]

---

💬 **聊聊看**：
[引发评论区讨论的直接问题]
[引导扣"1"或收藏的具体承诺]

#[标签1] #[标签2] #[标签3] #[标签4] #[标签5] #[标签6]
```

### 第五步：持久化保存与汇报
1. 将最终文档统一保存至 `outputs/小红书/YYYY-MM-DD-{主题}-小红书笔记.md`；
2. 封面图片原图统一保存在 `outputs/小红书/images/{name}_cover.jpg`；
3. 向用户汇报产出路径与核心亮点，完成交付。
